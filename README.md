# مطعم الحجي: موقع المنيو والطلب

موقع ثابت يُستضاف مجاناً على GitHub Pages، ويستخدم Supabase (مجاني) كقاعدة بيانات وتسجيل دخول للمديرين.

## الملفات

- `index.html`: صفحة المنيو والسلة والطلب للزبائن.
- `admin.html`: لوحة إدارة المنيو والطلبات (محمية بتسجيل دخول).
- `supabase/schema.sql`: الجداول وصلاحيات الوصول ودالة إنشاء الطلب.
- `supabase/seed.sql`: الأقسام والأصناف والأسعار من القائمة الرسمية (16 قسماً، 100 صنف، 15 خيار حجم).
- `assets/js/config.js`: إعدادات الموقع (رابط Supabase ومفتاح الوصول العام ورقم واتساب).

## أ) إعداد قاعدة البيانات (مرة واحدة)

1. أنشئ مشروعاً جديداً على https://supabase.com (خطة مجانية).
2. من القائمة الجانبية: **SQL Editor** ثم **New query**، والصق محتوى `supabase/schema.sql` واضغط Run.
3. في query جديد، الصق محتوى `supabase/seed.sql` واضغط Run. يمكن تشغيله أكثر من مرة دون تكرار الأصناف.
4. من **Authentication > Providers > Email**، عطّل خيار التسجيل الذاتي للمستخدمين الجدد (Allow new users to sign up) حتى لا يستطيع أحد إنشاء حساب إدارة.
5. من **Authentication > Users**، اضغط **Add user** وأنشئ حساب المدير ببريد وكلمة مرور.
6. في **SQL Editor** شغّل التالي بعد تغيير البريد إلى بريد المدير:

   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'you@example.com'
   on conflict do nothing;
   ```

7. من **Project Settings > API** انسخ:
   - **Project URL**
   - **anon public key** (المفتاح العام فقط، لا تنسخ `service_role` أبداً).

## ب) ربط الموقع

افتح `assets/js/config.js` وضع القيم:

```js
window.HAJJI_CONFIG = {
  supabaseUrl: "https://xxxx.supabase.co",
  supabaseAnonKey: "eyJ...",
  whatsapp: "9647701234567", // رقم المطعم بدون +
  restaurantName: "مطعم الحجي",
};
```

قبل ملء هذه القيم يعرض الموقع المنيو بشكل كامل، لكن الطلب يبقى غير متاح لأن التحقق من الأسعار يتم على الخادم.

## ج) النشر على GitHub Pages

1. ارفع الملفات إلى المستودع على الفرع `main`.
2. من **Settings > Pages** اختر:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد **/ (root)**
3. بعد دقيقة يصبح الموقع متاحاً على `https://<user>.github.io/<repo>/`.

## د) الأمان

- الأسعار تُقرأ من قاعدة البيانات داخل دالة `create_order` ولا يقبل الخادم أي سعر من المتصفح.
- الزائر يقرأ الأصناف النشطة فقط، ولا يستطيع رؤية الطلبات أو تعديل المنيو.
- المدير فقط (الموجود في جدول `admins`) يستطيع تعديل المنيو وتغيير حالة الطلبات.
- الأصناف لا تُحذف، بل تُخفى، فتبقى الطلبات القديمة كما هي.
- الفواتير تحفظ اسم الصنف والسعر وقت الطلب، فلا تتغير إذا تغيّر السعر لاحقاً.

## ملاحظات

- خطة Supabase المجانية قد تُوقف المشروع بعد فترة بدون نشاط، ويمكن إعادة تشغيله من لوحة Supabase.
- إذا أردت إضافة صور للأطباق، ضع رابط الصورة في حقل `image_url` للصنف من قاعدة البيانات. لا تُعرض أي صورة افتراضية حالياً.
- تحديث المنيو والأسعار يتم من `admin.html` دون تعديل أي كود.
